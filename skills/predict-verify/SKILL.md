# Predict-Then-Verify Skill

目标是让影响性操作的实际结果与已授权目标对应。遵循 [共享执行契约](../production-governance/references/workflow-contract.md)；预测只是待检验的假设，不是验证证据。

## 使用时机

- 安装、卸载、迁移、删除或修改关键状态，存在需要核对的副作用时。
- 用户已授权提交、推送或发布，需要确认目标和最终状态时；本 skill 不授予这些操作权限。
- 已有计划写清前置条件和验收时直接复用，不重复生成固定格式的预测块。
- 只读查询、常规小改动不单独激活；行数和文件数量本身不决定风险。

## 核心流程

### 1. 操作前确定可观察结果

记录必要信息即可，通常几行：

- **目标与依据**：操作对象、解析后的实际路径、版本或环境；来源是用户请求和已读项目契约。
- **前置条件**：所需权限、工作区基线、依赖和已确认的恢复材料。
- **预期结果**：可检查的状态或产物、不变量、允许的副作用，以及失败后的处置。
- **验证方式**：实际返回码、产物内容、独立验收或前后状态比较；不猜耗时、哈希、日志前三行或精确改动行数。

前置条件不满足时先补齐；缺少关键授权或需求不能用预测代替。任务内已有授权的必要可逆动作自主继续。

### 2. 执行后核对证据

保存命令自身返回码和相关输出，检查产物是否存在、内容是否符合验收、范围和副作用是否与计划一致。
测试检查真实发现与执行数量、跳过项和回归；零返回码、日志文字一致或模型自评都不能单独证明成功。
已有执行记录可以引用，不重复抄整段输出；没有运行或无法观察结果时明确记未验证。

### 3. 按差异处置

| 实际差异                                 | 处置                                                                                             |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 时间戳、日志顺序、格式或合理文件数量变化 | 核对验收仍成立；无需仅因文字不同停工                                                             |
| 命令失败、产物缺失或验收不符             | 暂停依赖该结果的后续操作，保存证据；按 systematic-debugging 调查代码、环境、输入或预期哪一项有误 |
| 必要的相邻文件修改，仍在授权目标内       | 说明理由并更新计划，验证相关影响后继续                                                           |
| 越出授权范围、触及他人改动或恢复边界不明 | 保留现场，先查清归属与影响；不盲目重试、回退或覆盖                                               |

有验收差异或范围漂移时用 self-critique 对照目标；预测不符只是调查信号，不能自动断言“理解错”。同一路径连续无进展时换调查方法，不刷重复自评。

## 示例：已授权卸载重装

**执行前**：确认目标是已检测到的两个宿主目录，备份现有受管内容与个人配置。预期卸载只处理清单归属内容；重装后版本和文件哈希匹配已验证源码，个人配置和无关文件保留。

**执行后**：保存实际卸载、安装结果和清单；逐项比较安装文件及配置。日志顺序变化不影响验收；任何文件缺失、未解释的配置变化或失败返回码都需要调查，不能只看“安装完成”文字。

## 验收标准

- [ ] 影响性操作前已明确实际目标、必要前置条件、预期状态和恢复边界。
- [ ] 结果来自实际执行和可观察产物，不以预测准确率代替业务或测试通过。
- [ ] 能区分无害日志差异、操作失败和授权范围变化；只暂停依赖失败结果的步骤。
- [ ] 用户既有修改得到保护；没有新增重复确认、自动提交或盲目回退。
- [ ] EXECUTE 的 QuestResult.validations 引用实际证据；VERIFY 按 quality-gates 判断通过、失败或未验证。

## 评估边界

这一流程不提供命令拦截或可信执行器。可用“安装成功但漏文件”“日志顺序变了但状态一致”“迁移返回成功但数据验收失败”检查规则覆盖；模型是否遵循、是否降低错误与成本，需要独立实测。
没有本项目对照数据时，效果、时间和 token 收益均为 unknown，不引用通用自反馈论文为本流程编造收益百分比。
